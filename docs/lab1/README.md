## Рішення
Попередній вибір для локального використання, обмежений цим синтетичним набором:

1. Модель requested/reported: `qwen3:1.7b` / `qwen3:1.7b`, псевдонім local; дата 2026-10-27.
2. Промпт v4, prompt_sha256 `c10566286251`.
3. Режим B, openai_chat через Ollama; без інструментів для golden-класифікації. Tool-випадки оцінені окремим t1, їхні числа не підмішуються у test.
4. Власні числа з [structured.md](structured.md): 21/25 = 0.84, 95% ДІ [0.65;0.94]; валідних 25/25; медіана 73 мс; валідно-але-хибно 4/25. API-ціна локального виклику $0, електроенергія й амортизація не оцінювалися.
5. Компроміс: v2 має більше правильних у цьому test (23/25), проте його ДІ [0.75;0.98] перетинається з обраним. V4 обрано за поведінкою на t24/t25 і строгим форматом B. Дані лишаються локально; затримка залежить від GPU/контексту. Схема не гарантує коректність дії.
6. Переглянути після нового незалежного набору, зміни digest/сервера, появи персональних даних, p95 понад 1.5 с або відновлення Gemini-порівняння.
