# Гіпотези до першого прогону відповідей

Набір data/lab3/queries.jsonl, test=25. Канонічна правильність визначається answer_correct у score.py. Рядок absent правильний за status=refused. Ненульові error_type виключаються та показуються окремо. Для кожної частки друкуються n і 95% ДІ Вілсона. Перетин інтервалів означає недостатньо даних для переваги.

## Г-1
RAG дає більше правильних відповідей за prompting. Підтвердження потребує неперетину ДІ та більшої кількості переходів хибно→правильно за правильно→хибно на спільних id.

## Г-2
RAG частіше правильно відмовляє на absent. Підтвердження потребує неперетину ДІ відмов із prompting і більшої частки RAG. За однакових часток або перетину інтервалів — недостатньо даних.

## Г-3
LoRA на dev і дозволених документах підвищує правильність порівняно з базовим prompting. Підтвердження потребує неперетину ДІ та більшої частки правильних. Якщо навчання чи застосування адаптера завершується виміряною відмовою, вердикт «прогону не було» із доказами в adapt.md.
