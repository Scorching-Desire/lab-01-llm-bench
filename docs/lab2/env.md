# Середовище

Вимірювання 17 листопада 2026 року. Windows 11 Enterprise LTSC, AMD Ryzen 5 7640HS, 39,2 GiB RAM, AMD Radeon 760M та NVIDIA RTX 4060 Laptop GPU (8188 MiB VRAM). Ollama 0.40.16.

Локальна модель `bonsai-2:2b` (`de2ccb4e7328`, 911 MB, завантажена 17 листопада) має вхід text/image. Живий `ollama ps` показав 1,1 GB, 100% GPU, context 16384, runner llamacpp. Це розмір резидентної моделі зі звіту Ollama та не окремий замір оперативної пам’яті процесу. Браузерні чи хмарні обчислення Ollama в цій матриці не використовувались. Хмарна модель `gemini-3.1-flash-lite` працює окремо через native API.

Canary clean на 1280 px у `results/lab2/01-clean-local-vision.jsonl`: 48 989 мс холодний старт, далі 1730, 2862, 3223, 3211, 3236 мс. Медіана без холодного старту **3211 мс, n=5**. Native Gemini на тому самому першому документі дав 3790 мс та правильну мітку. Затримка runner охоплює запит і локальну обробку. Пауза ліміту між документами до неї не входить.
