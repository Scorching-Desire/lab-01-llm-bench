# Правила проєкту для Lab 01 і Lab 02

- Не відкривай `.env`, `.env.*` та файли з ключами. Ключі завантажує лише CLI під час прогону.
- Не редагуй `results/**` вручну. Нові вимірювання дописують скрипти. Історичні результати зберігаються.
- Не редагуй `data/**` вручну. Нові артефакти Lab 02 створюють генератори. Дані й мітки Lab 01 заморожені.
- Не виконуй `git push`, `git reset --hard`, `git rebase` чи `git commit --amend` без мого явного підтвердження.

Працюй через `python -m uv sync --locked`. Перед комітом запускай `python -m uv run pytest`. Нові тести працюють без мережі. Додавай залежності через `uv add`.
